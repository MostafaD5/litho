# Litho

Litho is a responsive and modern frontend website template built with **HTML5**, **CSS3**, **JavaScript**, and **Bootstrap**. It's ideal for landing pages, business websites, or portfolio showcases.

## 🚀 Features

- 💎 Clean and modern UI
- 📱 Fully responsive layout
- 🎯 Built with Bootstrap 5
- ⚙️ Easy to customize
- 🌐 Cross-browser compatible
